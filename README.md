
# LensNest

LensNest is a responsive image-search app that will let users explore images by searching for topics. I chose a teal-and-cream colour palette to create a calm, nature-inspired look. I added topic suggestion chips to help users discover search ideas quickly. I also included an empty-state message and a responsive CSS grid to prepare the gallery for future image results.
